# Password Generator

**Date Finished:** July 16, 2026

This is a Python program that generates a strong, random password based on the user's desired number of letters, symbols, and numbers.

## What I Learned

Through building this project, I learned the following:

- **Using the `random` module:** I learned how to use `random.choice()` to pick random elements from a list (letters, numbers, symbols) and `random.shuffle()` to randomly reorder the characters in a list so the password isn't predictable.
- **Working with Loops and Ranges:** I used `for` loops combined with `range()` to repeat an action a specific number of times based on user input (e.g., adding 5 letters).
- **List to String Conversion:** I learned how to use the `"".join()` method to smoothly convert a list of characters back into a single string for the final output.
